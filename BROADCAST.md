# Руководство по рассылке сообщений

## Описание

Система массовой рассылки позволяет отправлять сообщения всем пользователям бота. Включает автоматическое сохранение пользователей, статистику и защиту от rate limits Telegram API.

## Возможности

- ✅ Автоматическое сохранение всех пользователей в базу данных
- ✅ Рассылка текстовых сообщений, фото, видео, документов
- ✅ Защита от блокировки Telegram (rate limit: 30 msg/sec)
- ✅ Статистика в реальном времени
- ✅ История рассылок
- ✅ Автоматическое отслеживание заблокировавших бота пользователей
- ✅ Админ-панель с полной статистикой

## Настройка

### 1. Добавьте ADMIN_IDS в .env

```env
# Telegram Bot Configuration
BOT_TOKEN=your_bot_token_here
BOT_USERNAME=your_bot_username
CHANNEL_ID=@your_channel_username
CHANNEL_URL=https://t.me/your_channel

# Admin IDs (через запятую, например: 123456789,987654321)
ADMIN_IDS=123456789,987654321

# UTM параметры для аналитики
UTM_SOURCE=qr_code
UTM_MEDIUM=offline
UTM_CAMPAIGN=subscription_discount
```

### 2. Узнайте свой Telegram ID

**Способ 1: Через бота @userinfobot**
1. Откройте @userinfobot в Telegram
2. Нажмите /start
3. Бот отправит вам ваш ID

**Способ 2: Через команду /status в вашем боте**
1. Запустите бота
2. Отправьте /admin (даже если вы еще не админ)
3. В логах бота будет ваш ID

### 3. Перезапустите бота

После добавления ADMIN_IDS перезапустите бота:

**Docker:**
```bash
cd ~/Bot
git pull
sudo docker-compose down
sudo docker-compose build
sudo docker-compose up -d
```

**systemd:**
```bash
cd ~/Bot
git pull
sudo systemctl restart telegram-bot.service
```

## Команды администратора

### /admin
Открывает админ-панель с доступными командами.

**Пример:**
```
🔧 Админ-панель

Доступные команды:
/stats - Статистика пользователей
/broadcast - Запустить рассылку
/history - История рассылок
/status - Проверка конфигурации бота

Ваш ID: 123456789
Администраторов: 2
```

### /stats
Показывает статистику по пользователям.

**Пример:**
```
📊 Статистика пользователей

👥 Всего пользователей: 523
✅ Подписанных: 412
❌ Заблокировали бота: 23
🎯 Активных: 500

📈 Конверсия: 78.8% (из всех пользователей)
```

### /broadcast
Запускает процесс рассылки.

**Шаги:**
1. Отправьте /broadcast
2. Бот покажет количество активных пользователей
3. Отправьте сообщение для рассылки (текст, фото, видео, документ)
4. Бот начнет рассылку с отображением прогресса
5. По завершении покажет статистику

**Пример использования:**
```
Вы: /broadcast

Бот: 📢 Запуск рассылки

Активных пользователей: 500

Отправьте сообщение, которое нужно разослать всем пользователям.
Поддерживаются: текст, фото, видео, документы.

Вы: [отправляете сообщение с текстом и фото]

Бот: ⏳ Рассылка в процессе...

Всего пользователей: 500
Отправлено: 250
Ошибок: 5
Прогресс: 250/500 (50.0%)

[После завершения]

Бот: ✅ Рассылка завершена!

Всего пользователей: 500
✅ Успешно отправлено: 487
❌ Ошибок: 13
📊 Успешность: 97.4%
```

### /history
Показывает последние 10 рассылок.

**Пример:**
```
📜 История рассылок

✅ Рассылка #5
   Текст: Новая акция! Скидка 70% на все товары до...
   Отправлено: 487/500 (97.4%)
   Дата: 2026-01-25 18:30:15

✅ Рассылка #4
   Текст: Важное обновление для подписчиков...
   Отправлено: 450/480 (93.8%)
   Дата: 2026-01-24 14:20:05
```

## Типы сообщений для рассылки

### Текстовое сообщение
Просто отправьте текст после команды /broadcast.

**Поддерживается HTML разметка:**
```
<b>Жирный текст</b>
<i>Курсив</i>
<u>Подчеркнутый</u>
<code>Код</code>
<a href="https://example.com">Ссылка</a>
```

**Пример:**
```
🎉 <b>Большая распродажа!</b>

Только до конца недели - скидка <b>70%</b> на все товары!

Переходите по ссылке: https://t.me/your_channel
```

### Фото с подписью
Отправьте фото с текстом в качестве подписи.

### Видео
Отправьте видео (поддерживается подпись).

### Документ
Отправьте файл/документ (поддерживается подпись).

2. Или отправьте текст "❌ Отменить рассылку"

## База данных

### Автоматическое сохранение пользователей

Бот автоматически сохраняет всех пользователей при:
- Команде /start
- Любом взаимодействии с ботом
- Проверке подписки

### Хранимые данные

- `user_id` - ID пользователя Telegram
- `username` - Username пользователя
- `first_name` - Имя
- `last_name` - Фамилия
- `is_subscribed` - Статус подписки на канал
- `is_blocked` - Заблокировал ли пользователь бота
- `created_at` - Дата первого взаимодействия
- `updated_at` - Дата последнего обновления

### История рассылок

Для каждой рассылки сохраняется:
- ID рассылки
- ID администратора
- Текст сообщения
- Количество пользователей
- Количество успешных отправок
- Количество ошибок
- Дата и время

## Защита от rate limits

Telegram ограничивает скорость отправки сообщений:
- **30 сообщений в секунду** для разных пользователей

Бот автоматически добавляет задержку 0.05 секунды между сообщениями для соблюдения лимитов.

**Скорость рассылки:**
- ~20 сообщений в секунду
- ~1,200 сообщений в минуту
- ~72,000 сообщений в час

## Обработка ошибок

### Пользователь заблокировал бота

Когда пользователь блокирует бота:
1. Бот получает ошибку `TelegramForbiddenError`
2. Автоматически помечает пользователя как заблокированного в БД
3. В следующих рассылках этот пользователь будет пропущен
4. Статистика обновляется

### Другие ошибки

- Сетевые ошибки - логируются, увеличивается счетчик ошибок
- Недоступный пользователь - пропускается
- Неверный формат сообщения - логируется

## Рекомендации

### ✅ Хорошие практики

1. **Не спамьте** - делайте рассылки не чаще 1-2 раз в неделю
2. **Ценность контента** - отправляйте полезную информацию
3. **Время рассылки** - лучшее время 10:00-12:00 и 18:00-20:00
4. **Тестирование** - сначала отправьте себе, проверьте форматирование
5. **Краткость** - держите сообщения короткими и понятными

### ❌ Чего избегать

1. Не отправляйте рассылки чаще 1 раза в день
2. Не используйте CAPS LOCK и множество эмодзи
3. Не отправляйте спам или рекламу сомнительных товаров
4. Не делайте рассылку в ночное время (23:00-07:00)

## Решение проблем

### Рассылка не запускается

**Проблема:** Команда /broadcast не работает

**Решение:**
1. Убедитесь, что ваш ID добавлен в ADMIN_IDS в .env
2. Перезапустите бота после изменения .env
3. Проверьте логи: `sudo docker-compose logs -f`

### Низкая успешность рассылки

**Проблема:** Много ошибок при рассылке

**Решение:**
1. Проверьте формат сообщения
2. Убедитесь, что фото/видео не слишком большие
3. Проверьте, не заблокирован ли бот Telegram за спам

### База данных пустая

**Проблема:** /stats показывает 0 пользователей

**Решение:**
1. Пользователи сохраняются только после взаимодействия с ботом
2. Отправьте /start в бот от нескольких аккаунтов
3. Проверьте, что файл bot_users.db создан в директории бота

## Поддержка
